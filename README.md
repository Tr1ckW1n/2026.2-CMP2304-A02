# Monta Grupo

Plataforma para alunos que precisam formar grupos de trabalho acadêmico. Quem já tem uma vaga aberta em seu grupo publica; quem está sem grupo busca, encontra e se candidata.

## Problema que a aplicação resolve

Formar grupos de trabalho nem sempre é simples: alunos que faltaram no dia da formação dos grupos, que trocaram de turma, ou que têm poucos contatos na sala acabam sem grupo até perto do prazo de entrega. O Monta Grupo centraliza a oferta e a procura de vagas em grupos, reduzindo esse atrito.

## Público-alvo

Alunos de graduação de qualquer curso que precisam formar equipes para trabalhos, projetos ou atividades em grupo.

## Tecnologias utilizadas

- **Cliente:** HTML5 semântico, CSS, JavaScript (evoluindo para React ao longo do semestre)
- **Servidor:** Node.js + Express (API REST)
- **Persistência:** SQLite

> Este projeto está sendo desenvolvido de forma incremental ao longo da disciplina de Tecnologia de Construção de Software I. As tecnologias podem ser ajustadas em etapas futuras, mantendo a coerência da solução.

## Funcionalidades

- Cadastro e login de aluno
- Publicação de vagas de grupo (disciplina, tema, vagas disponíveis, prazo, descrição)
- Listagem e busca de vagas abertas, com filtro por disciplina
- Candidatura a uma vaga
- Aceite/recusa de candidatos pelo autor da publicação
- Painel pessoal com publicações criadas e candidaturas enviadas
- Encerramento manual de uma vaga
